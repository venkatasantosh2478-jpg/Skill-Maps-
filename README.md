# Skills Map

Student competency and career skill mapping platform featuring interactive radar graphs, learning roadmaps, curated resources, and adaptive assessments powered by Google Gemini AI.

## Features

- **Competency Radar**: Visual spider chart mapping technical and soft skill proficiencies across 10 career dimensions.
- **Dynamic Learning Roadmap**: AI-generated milestone paths tailored to specific career targets.
- **Adaptive Assessments**: Real-time evaluation questions assessing mastery level.
- **ATS Resume Analysis**: Extract technology skills from resumes and detect gap areas for target roles.
- **Skills Demand Assistant**: Career chatbot answering questions on skill trends and study paths.
- **Admin Dashboard**: Student progress analytics, resource management, and opportunity tracking.

## Development

1. Install dependencies:
```bash
npm install
```

2. (Optional) Set your Gemini API key:
```bash
export GEMINI_API_KEY="your-api-key"
```

3. Start development server:
```bash
npm run dev
```

The application runs on `http://localhost:3000`.
