1. EXECUTIVE SUMMARY & PROBLEM STATEMENT
================================================================================

SkillMap is an AI-powered academic companion and career acceleration platform
engineered to bridge the deep, systemic divide between university educational
curricula and modern industry workforce expectations.

Traditional university education relies heavily on periodic examinations, letter
grades, and static syllabi that often trail industry practices by several years.
Students frequently graduate without a clear understanding of:
  - Exactly what technical and soft skills modern employers require.
  - Where their own real strengths and weaknesses lie.
  - Which specific milestones will turn their academic knowledge into a viable,
    job-ready portfolio.

SkillMap solves this challenge by introducing a real-time, multidimensional
competency ecosystem. Using Google Gemini generative AI models, Firebase cloud
storage with multi-tab offline synchronization, interactive 360° competency
radar graphs, and adaptive Item Response Theory (IRT) diagnostic testing,
SkillMap gives every learner an individualized, measurable path from enrollment
to high-impact career placement.

2.1 FRONTEND CLIENT ARCHITECTURE

                       micro-interactions.
  - Component Icons  : Lucide React iconography system.
  - Visualization    : Recharts (Radar, RadarChart, PolarGrid, PolarAngleAxis,
                       BarChart, LineChart).

2.2 DOCUMENT & REPORT GENERATION
  - PDF Generation   : jsPDF v2 with jspdf-autotable plugin for formatted,
                       multi-page corporate audit dossiers and system specs.
  - Canvas Rendering : HTML2Canvas and DOM-to-Image for exporting visual
                       radar charts, certificates, and portfolio badges.

2.3 BACKEND API & SERVER INFRASTRUCTURE
  - Server Framework : Node.js with Express.js written in TypeScript (server.ts).
  - Production Bundle: esbuild compiles server.ts into an optimized CommonJS
                       executable (dist/server.cjs).
  - Reverse Proxy    : Express acts as a reverse proxy, hosting Vite development
                       middlewares in dev and serving static assets in production.
  - Cloud Platform   : Containerized deployment on Google Cloud Run listening on
                       port 3000.

2.4 ARTIFICIAL INTELLIGENCE LAYER
  - Primary AI SDK   : @google/genai TypeScript SDK.
  - AI Models        : Google Gemini 2.5 Flash for high-speed, cost-efficient
                       structured JSON generations.
  - Proxy Architecture: All client AI queries are channeled through the server
                       endpoint (/api/ai/invoke-llm), keeping API keys strictly
                       confidential and protected from browser exposure.
  - Offline Fallbacks: Built-in deterministic JSON generator fallbacks ensure
                       zero user disruption during network outages or API limits.

2.5 DATA PERSISTENCE & USER AUTHENTICATION
  - Auth Provider    : Firebase Authentication (Email/Password & Google OAuth).
  - Cloud Database   : Cloud Firestore NoSQL document store.
  - Local Resilience : Firestore persistentLocalCache with multi-tab manager
                       (persistentMultipleTabManager) and browser LocalStorage
                       fallback layers for completely offline-tolerant operation.


================================================================================
3. CORE METHODOLOGY & DATA PHILOSOPHY
================================================================================

SkillMap abandons flat GPA grading in favor of an iterative, 4-step competency
loop:

1. DIAGNOSE (Skill Profiling & Adaptive Assessment)
   The learner undergoes initial track profiling followed by adaptive testing.
   Skills are broken down into granular vectors (e.g., Backend, Frontend,
   System Architecture, Problem Solving, Database, DevOps).

2. VISUALIZE (360° Competency Radar & Sector Benchmarks)
   Data is transformed into an intuitive radar visualization, immediately
   revealing operational strengths and critical gaps compared against live
   sector standards (e.g., Software, FinTech, HealthTech, Green Energy).

3. ACTIVATE (AI Learning Roadmaps, Lectures & Timetable)
   The platform curates tailored study milestones, automated lecture notes,
   and daily study blocks to close identified skill gaps without wasted time.

4. VALIDATE & CONNECT (Resume ATS Checks, Mentorship & Opportunities)
   Learners validate their real-world capabilities by auditing resumes against
   job descriptions, booking 1:1 sessions with industry leaders, and applying
   for verified internships and freelance gigs.

4.3 ADAPTIVE ASSESSMENT SYSTEM (`/assessment`)
--------------------------------------------------------------------------------
- Core Mechanism:
  * Employs Item Response Theory (IRT) principles for intelligent difficulty
    calibration.
  * Tests consist of 5 sequential questions per round.
- Adaptive Difficulty Scaling:
  * Baseline difficulty begins at 0.40 (on a 0.00 to 1.00 normalized scale).
  * Correct answers increase subsequent question difficulty (+0.15 up to 0.95).
  * Incorrect answers decrease subsequent question difficulty (-0.15 down to 0.15).
- Question Generation Architecture:
  * Dynamically queries Google Gemini 2.5 Flash via `/api/ai/invoke-llm` to
    synthesize novel, high-quality multiple choice technical questions
    calibrated to the exact numeric difficulty level.
  * Features an integrated, robust offline question bank (`quizBank.js`) covering
    all engineering tracks to guarantee zero-downtime execution.
- Instant Competency Graph Updates:
  * Upon quiz completion, the student's mastery score is calculated based on the
    peak difficulty reached.
  * Automatically invokes `bumpSkill()` to update Firestore and the student's
    radar chart in real-time.
  * Records detailed audit activity in the student's persistent activity log.

6. API SPECIFICATIONS & BACKEND INTEGRATIONS
================================================================================

6.1 POST /api/ai/invoke-llm
---------------------------
- Description : Primary backend proxy route for Google Gemini generative AI.
- Authentication: Valid session bearer token or authenticated user context.
- Payload Body:
  {
    "prompt": "Generate a multiple-choice question on Kubernetes at difficulty 0.75...",
    "systemInstruction": "You are an expert technical interviewer and academic assessor...",
    "responseFormat": "json"      // "text" | "json"
  }
- Response Body:
  {
    "success": true,
    "text": "{ \"question\": \"...\", \"options\": [...], \"correctIndex\": 0, \"explanation\": \"...\" }"
  }
- Fallback Strategy: If upstream Gemini services encounter rate limits or network
  delays, the Express server gracefully returns a structured offline payload
  drawn from local domain banks.

6.2 STATIC ASSET & HEALTH SERVICES
----------------------------------
- GET /health                  : Returns { status: "ok", timestamp: ... }
- GET /SKILLMAP_FULL_DOCUMENTATION.txt : Direct download of this full specification.

7. SECURITY, PRIVACY & OFFLINE PERSISTENCE
================================================================================

- Protected API Keys:
  Google Gemini API credentials are exclusively loaded in server environment
  variables (`GEMINI_API_KEY`) and are never exposed to the client bundle.
- Route Protection:
  React client-side routes are guarded by `<ProtectedRoute />` wrappers.
  Unauthenticated traffic attempting to access `/dashboard`, `/assessment`,
  `/roadmap`, or `/profile` is automatically redirected to `/login`.
- Role-Based Access Control (RBAC):
  Administrative paths (`/admin/*`) strictly verify user permissions before
  rendering management modules.
- Multi-Tab Offline Caching:
  Cloud Firestore is initialized with `persistentLocalCache` and
  `persistentMultipleTabManager`. Students on unstable university Wi-Fi can
  continue reading course materials, writing notes, and reviewing roadmaps
  without losing state.

8. DEPLOYMENT, BUILD & MAINTENANCE GUIDELINES
================================================================================

- Development Server:
  `npm run dev` executes `tsx server.ts` launching Express and Vite concurrently
  on port 3000.
- Quality Auditing:
  `npm run lint` executes ESLint with strict zero-error policy.
- Production Compilation:
  `npm run build` runs:
    1. `vite build` to compile optimized client JS/CSS into `dist/`.
    2. `esbuild server.ts --bundle --platform=node ... --outfile=dist/server.cjs`
       to produce the standalone backend runtime.
- Production Execution:
  `npm run start` executes `node dist/server.cjs` serving the full application
  on Google Cloud Run.
